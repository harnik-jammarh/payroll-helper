Odoo connection

For logged-in-tab mode: keep Odoo logged in in this browser and profile, enter its URL below, and click Connect. Payroll Tab Companion verifies this payroll page automatically. No API key or toolbar click is needed.

API key: in Odoo open your avatar → My Profile → Security → New API Key, copy it here. The key has the same rights as that user and is stored only in your local application data.

Accounting

Posting follows Odoo Payroll: each earning debits its expense account, each deduction credits its payable account, and net pay is credited to Salaries payable with the employee as partner. Entry date = last day of the month; journal = the structure's journal from Odoo (e.g. Salaries) unless you pick one here. Accounts imported from Odoo rules are used first; the accounts below are only fallbacks.
